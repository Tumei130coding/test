现在完成时长什么样：主动 has / have done　被动 has / have been done
它到底在说什么：过去发生的事对现在还有影响 —— 要么一直持续到现在，要么现在还看得见结果。
硬标志词：since + 时间点　for + 时间段　already　yet　ever　never　just　so far　in the last / past + 一段时间　…times（次数）
两条铁律：① since 从句自己用一般过去时，主句才用完成时　② 完成时不能和 yesterday / last… / …ago 连用

易混gone 还是 been

这一对是本节最爱考的辨析，更多习题里连着出现了四次（第 3、4、5、16 题）：
· has / have gone to　去了某地，人还没回来（说话时不在场）
· has / have been to　去过某地，人已经回来了（强调经历）
· has / have been in　待在某地（强调停留了多久）
另外：there / here / home 是副词，前面不加介词 —— 只能说 have been there，不能说 have been to there。
