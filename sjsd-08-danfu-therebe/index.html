单复判断（There be 句型）

初级语法 · 三看三定 第 8 节 · 对应讲义 P21–P22 · 共 — 个判分点

二定单复判断（There be 句型） 扫码看讲解

三看三定的第二步：找准真正的主语，再定谓语用单数还是复数。

第一步永远是划掉修饰成分，找出主语中心词。
The number of candles in a birthday cake is…　←　of 短语全是定语，划掉
There be 句型看 be 后面那个名词，不看 There；接了两样东西就用就近原则，谁离 be 近听谁的。
“有”只能用 there be，不能用 have —— 这是最常丢分的一条。
例题 课上讲，先自己动手
习题 课上练 扫码看讲解

速查哪些主语当单数看

下面这些主语，谓语一律用单数：
· One of + 复数名词　（中心词是 One）
· The number of + 复数名词　“……的数量”　←→　A number of 用复数
· nobody / no one / everybody / everyone / somebody / anybody
· nothing / everything / something / anything
· 不可数名词：furniture news information advice homework bread money
· Each of + 复数名词　（中心词是 Each）
