做之前把四条过一遍：
① 语序：从句一律陈述语序，看到 do / does / did / can / will 跑到主语前面就排除
② 疑问词：看答语 —— To do… 配 why，By doing… 配 how，地点配 where
③ 关系词：指人 who/that，指物 which/that；介词后面只能 which/whom； 先行词前有 the first / the only 只能用 that；what 永远不引导定语从句
④ 逻辑词：读出前后两句的关系 —— 转折 but/though，因果 because/so，条件 if/unless， not…until 直到才，祈使句 + and/or 看后半句是好是坏
