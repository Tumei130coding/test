doing 的三种用法

初级语法 · 情态动词与非谓语 第 3 节 · 对应讲义 P4–P6 · 共 — 个判分点

doing固定搭配后面填 doing 扫码看讲解

非谓语这一大块，八成的题只考三件事：填 doing、填 to do、还是填 done。先看空前面那个词是什么。

下面这些后面必须跟 doing，背熟就能秒答：

结构类　　逗号 + doing　介词 + doing（of / by / in / to / instead of / without…）　when / while + doing

固定短语
feel like doing 想做某事　　enjoy doing 喜欢做某事　　keep doing 持续做某事
give up doing 放弃做某事　　finish doing 完成某事　　avoid doing 避免做某事
can't help doing 忍不住做某事　　spend + 时间 + (in) doing 花时间做某事
put off doing 推迟做某事　　see / hear sb. doing 看见／听见某人正在做某事
mind (sb.) doing 介意（某人）做某事　　be busy doing 忙于做某事
consider doing 考虑做某事　　be interested in doing 对做某事感兴趣
look forward to doing 期待做某事　　be worth doing 值得做某事

两个最坑的 to：look forward to doing、be used to doing 里的 to 是介词，后面跟 doing，不是动词原形。

主语doing 做名词 扫码看讲解

动词想当主语，就得先变成 doing。句子开头缺主语、或者介词后面缺东西，都填 doing。

两条：
① 动名词做主语，一律当第三人称单数 —— 后面的谓语用 is / does / helps，不用复数。
　Walking with friends after dinner is a good way to relax.
② 介词后面只能跟名词或 doing：start by making…　instead of punishing…

专门记这一组，年年考：
· be used to doing　习惯于做某事　　I am used to drinking milk.
· used to do　过去常常做某事
· be used to do　被用来做某事

形容doing / done 做形容词 扫码看讲解

这一组只看一件事：说的是「人」还是「事物」。

· -ing 修饰事物：这东西令人怎么样　a boring film　His explanation was confusing.
· -ed 修饰人：人感到怎么样　I'm bored.　Lu Yao is interested in art.

做题只需两秒：看空所在那句话的主语是人还是物。（别看上一句的主语。）

常考的几对：interesting / interested　exciting / excited　boring / bored surprising / surprised　confusing / confused　amusing / amused　relaxing / relaxed
