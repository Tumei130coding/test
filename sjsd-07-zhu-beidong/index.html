主被动判断

初中语法 · 三看三定 第 7 节 · 对应讲义 P20–P21 · 共 — 个判分点

三定主被动判断 扫码看讲解

三看三定的第三步：看主语是做这个动作，还是被这个动作。

怎么判：把主语和动词连起来读一遍 —— 主语自己做得出来就是主动，主语是被安排、被处理的对象就是被动。
被动长什么样：be + 过去分词，时态全靠 be 来变 ——
　一般现在 is / am / are done　一般过去 was / were done　一般将来 will be done
　现在进行 is / am / are being done　现在完成 has / have been done
常见提示词：句中出现 by + 人、by hand 这类，基本就是被动。
例题 课上讲，先自己动手
习题 带 * 的两道是拔高题 扫码看讲解

例外主动形式表被动

不是所有“被”都要用 be done。下面这几个动词后面跟副词时，用主动表被动：
· sell well　卖得好　　· write smoothly　写起来顺
· wash well　耐洗　　　· read well　读起来通顺
· won't open / won't start　打不开／发动不了
共同点：主语是物，说的是这个物“本身的性质”，不是谁对它做了什么。习题 6 考的就是这个。
