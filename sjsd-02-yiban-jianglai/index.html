一般将来时

初级语法 · 三看三定 第 2 节 · 对应讲义 P10–P13 · 共 — 个判分点

时态三一般将来时 扫码看讲解

一看时间 → 定时态；二看主语 → 定单复数；三看主被动 → 定语态。

一般将来时长什么样：主动 will do（也可以说 is / am / are going to do）　被动 will be done
will 和 be going to：be going to do 早有打算、有迹象；will do 临时决定、单纯预测。will 后面永远跟动词原形。
常见标志词：tomorrow next week / year in the future in + 一段时间（多久之后） some day / one day soon How soon…?
例题 课上讲，先自己动手

重点主将从现

一句话记住：见 if / when 想到 will。
主句是将来时，if / when / as soon as / until 引导的条件、时间状语从句里不能用 will，要用一般现在时代替将来。
You will see the changes　if you come.　←　主句 will，从句现在时
例题 两句话把规则用熟
