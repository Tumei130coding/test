专项不规则动词 · 过去式 ／ 过去分词

对应纸质的五张空白动词表。每行只露一列当提示 —— 有时给原形，有时给过去式或过去分词 —— 另外两列要你自己填。比一直给原形难，但考试就是这么考的。

怎么用：先展开下面的全表看一遍，再收起来做挖空；一组做完点「对答案」，想换词就点「换一批」。
成绩单按第一次作答算，换一批再练不影响正确率，放心多练几轮。

几个容易丢分的点：
· AAA 型（cost / put / read / cut…）三个形式长得一样，但 read 的读音变了
· ABA 型（come—came—come　run—ran—run）过去分词又变回原形
· AAB 型只有一个：beat—beat—beaten
· 两种写法都对的：learnt / learned　dreamt / dreamed　smelt / smelled　got / gotten
