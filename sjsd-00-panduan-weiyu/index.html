导入判断谓语

三看三定的第一步，是先找准句子里哪个词是谓语——找错了谓语，后面看时间、看主语、看主被动全都白搭。

一、以下哪些是谓语？ 逐个判断，判完即时反馈 扫码看讲解
二、勾画出句子中的谓语 点击带虚线的动词把它标成谓语；粗体的都是动词，但不一定都是谓语
判断标准只有一条，从头用到尾：
光秃秃的 to do / doing / done 不是谓语；不是光秃秃的，就是谓语。
所谓“不光秃秃”，就是前面有 be（is/am/are/was/were）、have（have/has/had）、或者情态动词（will/can/must/should…）。

六条记忆法
  • 以 t 结尾的词，过去式与原形相同。如：put—put、let—let、cut—cut、beat—beat
  • 以 d 结尾的词，把 d 变成 t。如：build—built、lend—lent、send—sent、spend—spent
  • 以 n 结尾的词，在词后加 t。如：mean—meant、burn—burnt、learn—learnt
  • 以 ow / aw 结尾的词，把 ow / aw 变成 ew。如：blow—blew、draw—drew、know—knew、grow—grew
  • 含有双写字母的词，将双写改为单写，在词尾加 t。如：keep—kept、sleep—slept、feel—felt、smell—smelt
  • 含有元音字母 o / i 的词，将 o / i 变成 a。如：sing—sang、give—gave、sit—sat、drink—drank
  • 规则变化里的两个坑：
  • 双写最后一个字母 + ed：stop—stopped、step—stepped、spot—spotted、prefer—preferred、permit—permitted、nod—nodded、jam—jammed、drop—dropped、beg—begged
  • 非 a/e/i/o/u + y 结尾，变 y 为 i + ed：marry—married、carry—carried、hurry—hurried、study—studied
