语法词尾-s / -es / -ed

练习进度 0/11
01 · 发音总开关

摸着喉咙，判断清浊

清辅音只有气流，浊辅音和元音会让声带振动。词尾通常会顺着原词最后一个声音，选择更省力的读法。

○

清音：不振动

/p, t, k, f, θ, s, ʃ, tʃ/
≈

浊音：有振动

元音及 /b, d, ɡ, v, ð, z, ʒ, dʒ, m, n, ŋ, l, r/
音标说明：示范音频采用美式发音。学生熟悉的英式教材常写 /e/、/iː/；美式音标常写 /ɛ/、/i/。本讲义在相关词后同时注明两种常见标法。
02 · -s / -es

三种读法：/s/、/z/、/ɪz/

/s/

清辅音后

原词最后是清辅音（但不是 /s, ʃ, tʃ/）

/z/

元音或浊辅音后

原词最后是元音或浊辅音（但不是咝音）

/ɪz/

咝音后

原词最后是 /s, z, ʃ, ʒ, tʃ, dʒ/，多加一个音节

03 · -ed

三种读法：/t/、/d/、/ɪd/

/t/

清辅音后

原词最后是清辅音（但不是 /t/）

/d/

元音或浊辅音后

原词最后是元音或浊辅音（但不是 /d/）

/ɪd/

/t/ 或 /d/ 后

原词最后是 /t/ 或 /d/，多加一个音节
